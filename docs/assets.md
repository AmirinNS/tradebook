# Image assets

Every image in `static/img/` was made for tradebook. None comes from a stock photo site, and none contains third-party logos, brand names, real tickers, or readable text. They are covered by the repository's MIT license.

## Landing page illustrations

| File | Size | How it was made |
|---|---|---|
| `static/img/landing/hero.webp` | 1600x1000 | AI-generated with the Gemini image model through the Antigravity CLI, then resized and converted to WebP. |
| `static/img/landing/feature-journal.webp` | 800x600 | AI-generated with the Codex CLI's built-in image generation, then resized and converted to WebP. |
| `static/img/landing/feature-stocks.webp` | 800x600 | Same as above. |
| `static/img/landing/feature-screener.webp` | 800x600 | Same as above. |
| `static/img/landing/feature-learn.webp` | 800x600 | Same as above. |
| `static/img/landing/feature-play.webp` | 800x600 | Same as above. |

The prompts asked for the "Exchange ledger" palette from `DESIGN.md` (deep navy with blue, green and red accents) and banned text, digits, logos and watermarks. Each image was checked by eye for stray text before it was accepted.

## Logo and icons

`static/img/logo.png`, `static/img/logo-wordmark.png`, `static/img/favicon-32.png` and `static/img/apple-touch-icon.png` are the tradebook logo and its icon sizes, created for this project.
